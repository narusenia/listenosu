# listenosu! v0.1.2

Windows 10 / 11 (64-bit) only. Unofficial; not affiliated with osu! or ppy. Extract the zip and run `listenosu.exe`; keep `listenosu-helper.exe` next to it. The app is not code-signed, so SmartScreen may warn on the first launch.

## What's new

- **Launching a second time shows the running window.** Since v0.1.1 only one instance runs; now the second launch also brings the first window forward, including from the tray or the taskbar.
- **Space plays and pauses** while the window is focused (not while you type in a text field).

## Fixes

- **Hotkey recording.** Pressing Ctrl, Shift, Alt or the Windows key on its own no longer records a broken binding such as `Ctrl+ControlLeft`. An assigned hotkey now has a **Clear** button to return it to Unassigned. If you already saved a broken binding, press Clear.

## Known limits

- The new behavior was checked by launching the app twice from a script; it is not tested while another app is in the foreground (Windows may then only flash the taskbar button).
- Global hotkeys for symbol keys may fail to register.
- macOS and Linux builds are not available.

Full changes: https://github.com/narusenia/listenosu/compare/v0.1.1...v0.1.2

# listenosu! v0.1.2（日本語）

Windows 10 / 11（64 ビット）のみ。非公式で、osu! および ppy とは関係ありません。zip を展開して `listenosu.exe` を実行します。`listenosu-helper.exe` は隣に置いたままにしてください。コード署名をしていないため、初回は SmartScreen が警告することがあります。

## 新しいもの

- **2 つ目を起動すると、動いているウィンドウを出します。** v0.1.1 から多重起動は防いでいましたが、1 つ目のウィンドウも前面に出します（トレイやタスクバーに隠れていても戻ります）。
- **Space で再生 / 一時停止**（ウィンドウにフォーカスがあるとき。テキスト入力中は除く）。

## 修正

- **ホットキーの記録。** Ctrl・Shift・Alt・Windows キーを単独で押しても、`Ctrl+ControlLeft` のような壊れた割り当てを記録しません。割り当て済みのホットキーに **Clear** ボタンを足し、未割り当てに戻せます。すでに壊れた割り当てを保存している場合は、Clear を押してください。

## 既知の制限

- 新しい動作は、スクリプトから 2 回起動して確認しました。ほかのアプリが前面にあるときは未確認で、Windows の制限でタスクバーのボタンが点滅するだけになる可能性があります。
- 記号キーのグローバルホットキーは、登録に失敗することがあります。
- macOS と Linux 向けはありません。

変更の一覧：https://github.com/narusenia/listenosu/compare/v0.1.1...v0.1.2
